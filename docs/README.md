# Docs

One page per part of Solid Memo. New to the app? Read
[user-guide.md](user-guide.md). Working on the code? Start with
[architecture.md](architecture.md) and [testing.md](testing.md).
[glossary.md](glossary.md) explains the terms the pages use.

The pages are listed in [docs.ttl](docs.ttl): each page's group, its
place in the reading order, and a line on what it covers. The site's
list of the docs is built from it, and so is every page's "All pages"
([markdown.md](markdown.md#the-docs-index)).
